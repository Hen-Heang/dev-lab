## The filter (before any new course, tutorial, or project)

Ask in order:

1. Is it inside the current phase of `ROADMAP.md`?
   → No: write it in "Later" below and close the tab.
2. Will I build something with it in `exercises/` or the flagship
   project this week?
   → No: it's entertainment, not learning.
3. Does it produce a Feynman note (`notes/feynman/TEMPLATE.md`)?
   → No: I read it, I didn't learn it.

## One flagship, not six repos

Every new concept gets built into **one** flagship project
(DRMS-style: auth, roles, orders, inventory, audit logs, PL/SQL,
tests). `java-core-mastery-lab` stays as the practice scratchpad.
The other repos (`AuthHub`, `heang-api-center`, `heang-dev-lab`,
`spring-boot-lab`, `spring_jwt_authentication`) are frozen — read
them, harvest code from them, don't grow them.

## The weekly cycle (do not change it, just repeat it)

1. Learn one concept (current phase of `ROADMAP.md`).
2. Build it into exercises/ or the flagship.
3. Write the Feynman note from `notes/feynman/TEMPLATE.md`.
4. Review last week's notes from memory first.
5. One `/mock-interview` per week.
